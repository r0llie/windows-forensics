# Security policy

This project processes potentially sensitive forensic data. Do not include case artifacts,
personal identifiers, credentials, or machine-specific parser output in public issues or pull
requests.

For a suspected vulnerability, use GitHub's private vulnerability reporting for this
repository when it is enabled. If private reporting is unavailable, contact the repository
maintainer privately before publishing technical details. Include the affected tool/version,
the impact, and a minimal synthetic reproduction when possible.

Please do not attach real host captures to a vulnerability report unless the maintainer has
provided a secure transfer method and the data owner has authorized sharing.
